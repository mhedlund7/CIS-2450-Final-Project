## IX. Data Source Requirements

### Amount of Data:

It is important to make sure your data source provides enough data to support your downstream modelling and analysis tasks. A high-quality data source should provide around **50,000+ rows**. Please note that this is the threshold for the number of rows which should be a part of the analysis, so rows removed during data cleaning should **not be counted**. You should have 50,000+ rows **after** the data cleaning.

### Complexity of Data:

Additionally, your data source should provide enough interesting fields and **features** to look at apart from the target classification/regression feature. We can not give a number for this as sometimes a few valuable API response fields can hold a rich amount of information and sometimes we need more features to get a complete picture. Generally, you should have **at least 7-10 columns**. But this number is more flexible and can vary widely.
