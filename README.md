## Dashboard

An interactive project dashboard is available in `dashboard.py`.

### Run

1. Install dependencies:
   - `python -m pip install -r requirements.txt`
2. Start the dashboard:
   - `python dashboard.py`
3. Open:
   - [http://127.0.0.1:8050](http://127.0.0.1:8050)
